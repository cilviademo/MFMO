## Schema manifest

`docs/SHAREPOINT_SCHEMA_MANIFEST.md`, generated by
`scripts/gen_schema_manifest.py`. 17 lists, 284 columns, with internal name,
type, required, indexed and choice vocabulary for every column.

**Internal names are immutable and everything binds to them.** Every name in
the schema is a plain identifier — no spaces, so no `_x0020_`, none over 32
characters — enforced by `eom_schema.ListDef.validate()`.

Reconciliation runs in the direction that matters: not "does the schema have
what we wrote", but **"did we write anything the schema does not have"**.
`tests/test_schema_manifest.py` checks the three positions where a wrong name
reads blank instead of erroring:

| Position | What a wrong name does |
|---|---|
| `SortByColumns(t, "X", …)` | does not sort, does not complain |
| `Patch(list, r, { X: … })` | writes nothing |
| `Filter(list, X = …)` | matches nothing, reports success |

Verified by deliberately introducing a typo and confirming the suite fails.
